# EduManage - نظام إدارة الطلاب للمعلمين

تم تحويل هذا النظام من واجهة أمامية فقط تعتمد على `LocalStorage` إلى نظام متكامل يعتمد على الخادم (Full-stack) باستخدام Node.js و Express مع قاعدة بيانات SQLite لتخزين المستخدمين (المعلمين) وبياناتهم بأمان.

## الهيكل الجديد للمشروع
- `frontend/`: يحتوي على ملفات الواجهة (HTML, CSS, JS) المنفصلة.
- `backend/`: يحتوي على السيرفر (Node.js) متصل بقاعدة بيانات PostgreSQL السحابية.

## المميزات الجديدة
- **نظام تسجيل الدخول:** مصادقة آمنة باستخدام JWT وتشفير كلمات المرور بـ bcrypt.
- **تعدد المستخدمين:** يمكن لكل معلم (User) أن يكون له بياناته وطلابه ومجموعاته المستقلة عن المعلمين الآخرين.
- **لوحة تحكم للمدير:** صفحة منفصلة بالكامل (`/admin`) تتيح لمدير النظام إضافة/تعديل/حذف حسابات المعلمين.
- **قاعدة بيانات سحابية:** يعمل النظام بقاعدة بيانات PostgreSQL (يمكن إنشاؤها مجاناً في Neon.tech) مما يجعله مثالياً للاستضافات المجانية.

## 🚀 طريقة التثبيت والتشغيل

### 1. تثبيت المتطلبات (Dependencies)
تأكد من وجود [Node.js](https://nodejs.org) مثبتاً في جهازك.
افتح سطر الأوامر (Terminal) وانتقل لمجلد المشروع، ثم إلى مجلد `backend`:
```bash
cd backend
npm install
```

### 2. إعداد المتغيرات البيئية (Environment Variables)
قم بإنشاء حساب في منصة [Neon.tech](https://neon.tech) أو [Supabase](https://supabase.com) لإنشاء قاعدة بيانات PostgreSQL مجانية. انسخ رابط الاتصال (Connection String).
يوجد ملف `.env` داخل مجلد `backend/`. يمكنك تعديله كالتالي:
- `PORT`: المنفذ الذي يعمل عليه الخادم (افتراضياً 3000).
- `JWT_SECRET`: مفتاح التشفير الآمن.
- `DATABASE_URL`: ضع فيه رابط اتصال قاعدة البيانات (PostgreSQL Connection String).

### 3. تشغيل الخادم
لتشغيل النظام، نفذ الأمر التالي داخل مجلد `backend`:
```bash
node server.js
```
سيظهر لك: `Server running on port 3000`

### 4. استخدام النظام
بعد تشغيل الخادم، يمكنك الوصول للموقع عبر المتصفح:
- **الموقع الأساسي للمعلمين:** [http://localhost:3000](http://localhost:3000)
- **لوحة تحكم المدير:** [http://localhost:3000/admin](http://localhost:3000/admin)

## 🛡️ لوحة التحكم وحساب المدير
النظام يقوم بإنشاء حساب مسؤول افتراضي تلقائياً عند أول تشغيل.

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin`

من لوحة التحكم تستطيع:
1. تغيير كلمة المرور لحسابك.
2. إضافة حسابات معلمين جديدة بإعطائهم اسم مستخدم وكلمة مرور.
3. يمكن للمعلم تسجيل الدخول من الواجهة الأساسية واستخدام النظام.

> ⚠️ **ملاحظة:** صفحة المدير منفصلة تماماً عن الواجهة الرئيسية حتى لا يراها المعلمون، وتتطلب صلاحيات "Admin" للدخول.

## 🌐 رفع المشروع على Server/Hosting حقيقي

بما أن المشروع يستخدم Node.js و SQLite، فهو سهل الرفع جداً على خدمات مثل **Render, Railway, Fly.io, أو VPS الخاص بك**.

**الخطوات العامة:**
1. ارفع المشروع إلى GitHub.
2. في منصة الاستضافة (مثل Render)، اختر إنشاء Web Service.
3. اربط حساب GitHub واختر مستودع المشروع.
4. اجعل أمر التثبيت: `cd backend && npm install`
5. اجعل أمر التشغيل: `cd backend && node server.js`
6. أضف الـ Environment Variables (مثل `JWT_SECRET` ليكون قوياً وعشوائياً).
7. *تنبيه:* مع خدمات الاستضافة المؤقتة (مثل الرصيف المجاني لـ Render)، قد يتم مسح ملف `database.sqlite` عند إعادة التشغيل. للاستخدام الفعلي الآمن، يُفضل استخدام استضافة تتيح Persistent Storage، أو تغيير الـ DB إلى Postgres إذا أردت الرفع المجاني.
